# Football Prediction Brain

Vault badawczy do budowy ilościowego modelu predykcyjnego meczów piłkarskich.

## Start

Otwórz ten folder jako vault w Obsidianie, a następnie zacznij od [[00 - Mapa projektu]].

## Zasady projektu

- model zwraca rozkład prawdopodobieństwa, nie pojedynczy „typ”;
- każda nowa cecha musi poprawić wynik poza próbą;
- każda informacja ma znacznik czasu i musi być dostępna w chwili predykcji;
- model sportowy, benchmark rynkowy i decyzja bettingowa są oddzielnymi warstwami;
- prostszy model pozostaje, jeżeli bardziej złożony nie daje mierzalnej poprawy.
